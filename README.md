# baiwei-clientside-api

## Description
baiwei-clientside-api is a Restful api service for BaiWei online shop to process client-side request.

## Tech-Stack
baiwei-clientside-api uses a number of open source projects to work properly:

- [Express](https://expressjs.com/)
- [Sequelize](https://sequelize.org/)

## Install dependencies
Install and build the dependencies, service will run on port 3000 in default.
```sh
npm install
```

## Run and Debug service
run service
```sh
npm run start
```

debug service
```sh
npm run debug
```

## Auto-gen API docs
```sh
npm run swagger-autogen 
```
